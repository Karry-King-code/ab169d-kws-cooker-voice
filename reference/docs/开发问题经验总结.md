## 一、为什么这次串口卡了那么久？（自我检讨）

**根因**：全程在"猜"引脚和延时，没先读 `reference/chip/` 的数据手册。

| 猜测 | 事实（手册/实测） |
|---|---|
| 以为 printf/命令帧在 PA8，逻辑分析仪接 pin4 就行 | **pin4 实测是 PA7**，PA8 发不到 pin4 |
| 以为 pin5 能用 HUART(PA5/6) | **pin5 可能实际是 PA4**（HUART 不支持） |
| 以为 `delay_us()` 参数控制 bit 宽度 | **参数不生效**（bit 固定 989us） |
| 以为 `rdcycle` 能精确延时 | **芯片不支持 → 死循环卡系统** |
| 以为 USB-TTL 收到 0x00 是 HUART 问题 | **其实是没接对 PA10（pin2）**，接对后立刻通 |

**教训**：
1. **先读 `docs/芯片手册总结-AB169D.md` + 原理图 + reference/chip 手册**，确认引脚/外设支持，再写代码
2. **接线必须确认接对实际引脚**（本项目接对 PA10 后串口 1 秒通）
3. **别猜"应该能行"，要验证**（手册/测量/试）

## 二、已解决问题清单（根因 + 修复）

| 问题 | 根因 | 修复 |
|---|---|---|
| 播报音质噪/小声 | 8kbps 低码率 + 音量不足 | loudnorm 响度 + xcfg 音量 50 + lowpass 压噪 + DAC_DNR |
| 唤醒后播报识别死 | 播报阻塞识别中断 | 异步播报（中断设标志，主循环 sound_poll 播放）+ 播报暂停识别 |
| 命令没回应 | 词表/映射顺序未对齐 | top+2 线性映射（词表/Excel/res 三对齐） |
| 上电欢迎语 | 43条MP3塞不下 | 压缩(8kbps)+裁静音 → res.bin |
| 错误/没听清误触 | 阈值低 | 1500/800→2500/1200，防抖 20 帧 |
| 串口命令帧发不出 | **pin 没接对（PA10）** | HUART PA10(pin2) 4800 2停止位 |

## 四、以后怎么避免"猜"

1. **每次动引脚/外设/硬件前** → 读 `docs/芯片手册总结-AB169D.md` + 原理图分析
2. **有疑问先问**（原厂/客户/看手册），不要假设"默认值"
3. **接线必须验证**（万用表/逻辑分析仪确认实际信号引脚）
4. **新问题解决后** → 追加到本文件（根因 + 修复 + 教训）

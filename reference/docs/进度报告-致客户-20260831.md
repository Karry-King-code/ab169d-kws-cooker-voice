## 二、语音资源情况

- 客户指令表 61 条去重后共 **43 条回应语**,已 100% 生成并灌入语音模块(逐条与指令表核对零缺失);
- 另新增 2 条流程播报语("已结束,进入保温状态"/"保温已结束,欢迎下次使用"),**全部 45 条齐备**;
- 全部语音统一响度校准,音量一致,无忽大忽小。

## 三、音质说明(重要,涉及产品板选型)

测试板实测确认:语音模块内部链路(解码/DAC)输出正常,当前听感上的"沙哑"来自**功放(8002)与小喇叭的硬件特性**,属芯片外限制。为使产品达到最佳听感,建议产品板选型时:

1. 喇叭选用额定功率匹配、频响较宽的型号(8Ω 2W 以上为宜);
2. 功放可考虑低失真型号(或沿用 8002 并实测确认);
3. 语音模块侧参数(DAC 增益/降噪)已调至当前硬件最优,产品板换件后可再联调一轮。

## 四、串口对接说明(待贵方确认)

| 项 | 参数 |
|---|---|
| 帧格式 | `A5 FA \| 指令ID \| 校验和 \| FB`(5 字节定长,校验和 = A5+FA+ID 低 8 位) |
| 波特率 | 4562 bps(可按贵方主控方便性调整) |
| 接口 | UART TX,单工 |
| 指令 ID | 即语音词表编号(1~36,详见词表附录) |

**请贵方确认**:AD248B 侧接收协议/波特率是否符合预期,以及产品板上串口走线的引脚分配。

# 语音模块开发总结（AB169D 电饭煲）

> **项目**：客户 colorman 陶瓷电饭煲的语音模块（AB169D）。模块只做"识别+播报"，命令经串口发给客户主控（Jieli AD248B）。
> **状态**：✅ 语音识别 + 43条播报 + 系统语 + 串口命令帧全部打通。

## 2. 架构

```
MIC → SDADC → kws_classify → top(ID)
   → 唤醒门控(wake_ctrl) → sound_request(异步) → 主循环sound_poll播放
   → uart_cmd_send(top) → HUART(PA10) → 主控
```

- **异步播报**：识别中断只设标志（sound_request），主循环 sound_poll 播放（避免阻塞中断）
- **播报暂停识别**：asr_pause 跳过识别帧，防喇叭声回灌误识别
- **命令→回应语映射**：词表顺序/Excel/res 三对齐 → `resp_id = top + 2`（一次加法，无查表）

## 3. 关键模块（新建/修改）

| 文件 | 作用 |
|---|---|
| `sound_res.c/h` | 播报核心：res 资源播放 + 异步播报(sound_request/poll) |
| `uart_cmd.c/h` | 串口命令帧：HUART PA10 发送 `0xA5 0xFA|ID|校验|0xFB` |
| `bsp_asr.c` | 识别流水线 + 唤醒门控 + 错误/没听清检测 + uart_cmd 触发 |
| `wake_ctrl.c/h` | 唤醒状态机（30s 保持）+ is_on 查询 |
| `main.c` | 上电播欢迎语 + bsp_huart_init |
| `config.h` | HUART_EN=1, HUART_TX_MAP=PA10, DAC_DNR, 音量 |

芯片识别

AB169D 是 中科蓝讯 (Bluetrum Technology Co., Ltd.) 推出的智能语音控制 SoC。

项目值
制造商 中科蓝讯 (Bluetrum) — sales@bluetrum.com / project@bluetrum.com
系列AB16x 系列
型号对比 AB169D: 4Mbit (512KB) Flash  |  AB169C: 2Mbit (256KB) Flash
CPU RISC-V 32-bit (rv32imac) + DSP 指令, 160MHz max
存储器内置 NOR Flash + 56KB SRAM + 16KB Cache
音频前端内置 MIC 放大器 + 高性能单通道 Σ-Δ ADC + 3bit Class-AB Mono DAC
电源管理内置 PMU，Capless LDO，1.8V~5.5V 供电范围
应用场景智能家居、智能玩具、智能照明、语音开关
